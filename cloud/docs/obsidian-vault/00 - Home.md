# Welcome to the Solar-Wind Energy Scheduler Knowledge Base

This Obsidian vault contains the complete engineering documentation for the automated solar site scheduling system. It is designed to be the primary source of truth for understanding the architecture, modules, features, and code of the project.

## How to Navigate This Vault

The vault is organized into several sections, each serving a specific purpose. Use the file explorer to navigate the structure, or start with the main architectural documents below.

- **[[10 - Architecture/11 - System Overview|System Overview]]**: Start here for a high-level introduction to the project, its goals, and its overall architecture.
- **[[50 - Features/51 - Master Feature Registry|Master Feature Registry]]**: A central registry of all major features, with links to detailed documentation.
- **[[10 - Architecture/12 - Backend Logic Architecture|Backend Logic Architecture]]**: A deep dive into the core scheduling algorithms and business logic.
- **[[30 - Code Reference/31 - Cloud|Cloud Code Reference]]**: Detailed documentation for each source file in the `cloud` module.

## Main Sections

- **[[10 - Architecture]]**: High-level diagrams, data flow explanations, and architectural decisions.
- **[[20 - Modules]]**: Documentation for the major components of the system (`cloud`, `backend`, `analysis`).
- **[[30 - Code Reference]]**: Automatically generated and manually curated documentation for the source code.
- **[[40 - Developer Playbooks]]**: How-to guides for common development tasks, like adding a new site.
- **[[50 - Features]]**: Descriptions of system features and their implementations.
